# 回答の書き方

このディレクトリの `*.md`（この README を除く）が回答です。ファイルの分け方は自由ですが、
カテゴリごとに `01-basics.md`、`02-mining.md` … と分けておくと差分が読みやすくなります。

質問そのものは `../questions.tsv` にあり、ここには書きません。見出しの番号で結び付けます。

```markdown
## 1-7

1 BTC は 1 億 satoshi です。satoshi（sat）はビットコインの最小単位です。

<!-- more -->

ブロックチェーン上の金額はすべて satoshi の整数で記録されていて、
「0.5 BTC」は 50,000,000 sat のことです。

関連: 1-12, 1-13
出典: https://github.com/bitcoin/bitcoin/blob/master/src/consensus/amount.h
更新: 2026-09-26
```

- `## <番号>` から次の `## ` までが 1 問分です。番号は `questions.tsv` と同じもの
- 空行で段落を分けます。段落の中の改行はそのまま表示されるので、`- ` の箇条書きも使えます
- `<!-- more -->` より上が最初に見える答え、下が「もっと詳しく」です（無くても構いません）
- `関連:` は画面に質問へのリンクとして出ます。存在しない番号を書くと起動に失敗します
- `出典:` は 1 行に 1 つ。何行でも書けます
- `更新:` はその答えの事実を最後に確かめた日です。半減期のように時期で変わる答えには必ず書きます

回答が無い質問も判定の対象です。当たった場合は「回答を準備中です」と表示されます。
