bird API 🐦

リクエストするとランダムに鳥の画像を返す API です。画像は Wikimedia Commons から取得しています。

読み込み中…

エンドポイント

パス内容
/api/birds/image/randomランダムな 1 枚
/api/birds/image/random/{count}ランダムに最大 50 枚
/api/birds/image/redirect画像へ 302 リダイレクト（<img src> 用）
/api/birds/list/allグループと種の一覧
/api/birds/catalog和名・英名・学名つきの一覧
/api/bird/{group}/images/randomそのグループからランダムに 1 枚
/api/bird/{group}/{species}/images/randomその種からランダムに 1 枚
/api/bird/{group}/{species}/imagesその種の画像をすべて
画像の著作権は各撮影者に帰属します。ライセンスと作者はレスポンスの attribution に含まれます。 出典: Wikimedia Commons
